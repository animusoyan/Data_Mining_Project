## Probability methods and controls

Raw probabilities remain exactly as stored/generated by the frozen pipeline. The only learned calibration parameter is an intercept b: expit(logit(p_raw)+b), with slope fixed to 1. The unpenalized binary log-loss derivative is mean(expit(logit(p_raw)+b)) minus observed calibration prevalence; brentq finds its unique finite root with xtol=1e-12. No full sigmoid slope, isotonic fit, class weights, rolling update or calibration search is used.

Numerical convention: clip probabilities to [1e-12,1−1e-12] only for calibration logits and log-loss evaluation; retain raw probabilities unchanged for raw Brier/ranking/classification. Use log1p/logaddexp and scipy.special.expit. An all-one/all-zero calibration target has no finite unconstrained optimum and is explicitly rejected; all actual calibration periods contain both classes. Clipping can create ties at extreme endpoints; observed AUC/AP changes and equivalent-threshold boundary counts are audited.

Constant controls use either the base-training-month observed prevalence or calibration-month observed prevalence. Neither uses threshold or assessment outcomes. Controls use threshold 0.5 only for descriptive classification columns; they are primarily probability-level references.
